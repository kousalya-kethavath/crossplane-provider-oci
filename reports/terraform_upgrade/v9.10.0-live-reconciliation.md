## Coverage limits

This is a live Identity-service CRUD/restart smoke test across both scopes, not an all-service acceptance run. The two namespaced ProviderConfigs demonstrate separate cache identities with the same principal; they do not establish cross-tenant authorization isolation. API-key credential rotation and other authentication modes remain covered by the existing local tests, not this live run. Newly added v9.10.0 services/resources were generation/build/selective-construction tested locally, but were not provisioned here. The branch controller was deployed directly; xpkg package installation/upgrade was not tested.

Raw local evidence (OCI/Kubernetes snapshots, binary/module provenance, phase logs and metrics) is retained under `.work/validation-v9.10.0/live/` and is intentionally excluded from Git. No test cloud resources remain.
