## Generation and CRD audit

The v9.10.0 schema was extracted using `terraform providers schema -json` from a local vendored build of the exact upgrade commit. Release documentation was exported from tag v9.10.0. The standard `apis/generate.go` directives generated APIs, controllers, CRDs, examples, runtime manifests and scheme-based resolvers for both scopes.

The baseline is the tracked main CRD/schema snapshot, with baseline config/client/generator tests passing. Baseline CRDs were not regenerated. The machine-readable companion JSON lists each added and changed CRD.

| Measure | v9.0.0 | v9.10.0 |
|---|---:|---:|
| Terraform resources | 1006 | 1023 |
| Terraform data sources | 2382 | 2426 |
| Generated managed resources per scope | 999 | 1016 |
| CRD files including ProviderConfigs | 2003 | 2037 |

- Added CRDs: 34 (17 resources across two scopes).
- Removed CRDs: 0.
- Structurally modified CRDs: 54.
- Documentation-only CRD modifications: 14.
- Flagged schema/behavior risks: 0 under the checks below.
- Additive/relaxed field changes across both scopes: 388.
- Changed descriptions containing deprecation notices: 20 (see JSON for paths and wording).

The audit recursively checks removed properties, type changes, newly required fields, enum restrictions, changed defaults, tighter numeric/length/item/property bounds, patterns, schema composition changes and removed served version entries. It ignores descriptions and titles. This static comparison does not prove service-side compatibility and does not automatically infer resource renames.

The new resources cover DRG NAT policies, Data Safe, DB@AWS key pools, Generative AI routing profiles and OCI Product Catalog. These additions align with the v9.1.0–v9.10.0 upstream [release notes](https://github.com/oracle/terraform-provider-oci/blob/v9.10.0/CHANGELOG.md). WLMS removals in this interval affect Terraform data sources, not the managed-resource CRD inventory.
